# To-Do List

A simple and beginner-friendly To-Do List web application built using HTML, CSS, and JavaScript.

## Features

- Save user's name
- Add tasks with a date
- Mark tasks as completed
- Undo completed tasks
- Edit tasks
- Delete individual tasks
- Select multiple tasks using checkboxes
- Delete multiple selected tasks at once
- Filter tasks
  - All
  - Pending
  - Completed
- Display total, completed, and remaining tasks
- Store tasks using LocalStorage
- Basic input validation
- Simple and responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- JSON
